## 수정 내용

- 첫 물리 페이지 키: Android 4.4의 터치 모드에서 빠져나올 때 첫 탐색 키가
  초점 선택에 소비되는 현상을 실제 입력으로 재현했다. ReaderView가 터치 모드에서도
  초점을 유지하게 수정한 후 첫 입력부터 페이지가 바뀌는 것을 확인했다.
- 상태 메시지: 홈과 목록에서 40dp 높이를 항상 확보하고 한 줄로 표시한다.
  비동기 요청의 대기·성공·실패 시 목록 경계, 표시 행 수, 페이지, 하단 버튼 위치를 비교했다.
- 초기 로그인: 비로그인 상태의 새 실행에서 로그인 창을 열고, 자동 로그인 실패 시에도
  입력 창으로 연결한다. 중복 로그인 창을 방지하며 화면 재생성 시 진행 중이던 로그인을 복구한다.
- 최신 회차: 공식 회차 목록의 최신순 응답에서 실제 `EP.` 문구를 읽는다.
  등록 편수나 뷰어 ID로 최신 회차를 추정하지 않는다. 보이는 행만 조회하며 캐시를 사용한다.
  상세 문구만 갱신하여 행의 초점·페이지를 유지하고 화면이 바뀐 뒤 도착한 결과는 폐기한다.
- 성인 모드: 계정 메뉴에서 서버의 현재 상태를 확인하고 명시적인 켜기·끄기를 제공한다.
  변경 후 서버 상태를 다시 확인한다. 로그인·모드 꺼짐·본인인증·연령 제한을 구분하고
  필요한 동작을 안내한다. 인증과 열람 권한은 서버의 판정을 따른다.

## 검증 환경과 결과

- Windows JBR 25를 WSL의 Java 경로 변환 도구로 실행했다.
- Android API 19 플랫폼으로 컴파일하고 APK 서명을 검증했다.
- 단위 테스트 201개가 통과했다.
- Android 4.4.2 ARMv7, 600×800/mdpi AVD에서 24개 검사가 통과했다. 실패와 생략은 없다.
- 실제 공개 사이트의 HTTPS, 목록, 검색, 회차, 무료 본문 및 최신 `EP.79` 조회를 확인했다.
- 성인 모드 오류별 대화상자와 ON/OFF 설정 화면은 합성 응답으로도 각각 검사했다.
- 대화상자 전환 도중 다음 입력을 보내던 테스트 경쟁 조건을 발견했다. 창 제거와
  Activity 초점 복귀를 기다리도록 보완한 뒤 전체 검사를 다시 통과했다.
- `ui-library.png`, `ui-reader.png`의 합성 화면을 직접 열어 검토했다.

자동 테스트에는 `me.crema.novelia.validation`을 사용했다. 실제 계정 로그인과는
분리하여 실행했고, 비밀번호·쿠키·본문을 테스트 결과에 저장하지 않는다.
공유 AVD의 전면 앱 충돌을 확인한 뒤 실계정 검증용으로 `Novelia19ARM`을 별도로 생성했다.

빌드와 검증 로그는 Git에서 제외된 `build/recovery-20261003/`에 있다.
크레마 실기기에서의 버튼 코드와 EPD 갱신은 별도의 실기기 검증 대상이다.

## 실제 계정 검증

사용자가 명시적으로 허용한 로그인으로 전용 API 19 AVD에서 확인했다.
이메일과 비밀번호는 공식 로그인 요청에만 사용했으며, 앱의 비밀번호 저장·자동 로그인은 끈 상태였다.
로그인된 서재에서 화면에 보이는 4개 작품의 실제 최신 회차 표기를 확인했다.

요청받은 작품 343176의 첫 회차 뷰어 4390049에서 다음을 확인했다.

- 초기 성인 모드는 꺼져 있었다.
- 사이트가 실제로 보내는 `성인모드가 꺼져있는 상태입니다.` 문구가 기존의 일반 오류로
  처리되는 것을 재현했다. 이 고정 문구를 접근 제한 분류에 추가하고 회귀 테스트를 만들었다.
- 수정한 앱에서 같은 회차를 열면 `성인 모드 꺼짐` 안내와 `성인 모드 켜기` 버튼이 표시됐다.
- 안내 버튼을 누르면 서버의 모드 변경을 확인한 뒤 요청했던 본문이 열리고 진행률 `0%`가 표시됐다.
- 본문을 터치한 후 첫 PAGE_DOWN 입력으로 진행률이 `0%`에서 `5%`로 바뀌었다.
- 설정 화면에서 `성인 모드 켜짐`을 확인한 뒤 `끄기`를 눌러 `성인 모드 꺼짐`으로 돌아오는 것을 확인했다. 검증 종료 시 최초 상태인 OFF를 유지했다.

실계정 응답 원문·쿠키·본문·비밀번호를 Git이나 검증 결과에 기록하지 않았다.
테스트용 비밀번호 파일은 Git에서 제외했다. APK는 `dist/novelia-0.1.0-preview.apk`이다.
최종 일반 APK SHA-256: `dd50831590b0ab390ce4c1a76228b65bc6e36f2e48e4b5b8d32c324486867a6a`.
