# 구글 계정 연결 — PC 세션 가져오기

이 앱은 구글 비밀번호를 입력받지 않습니다. PC에서 공식 노벨피아에 정상
로그인한 후 **노벨피아 도메인 쿠키만** 명시적으로 내보내고, 기기에서
선택한 파일을 가져오는 실험적 방식입니다. 서버의 기기/IP 정책, 세션 만료
등으로 연결이 거절될 수 있습니다. 실제 계정 성공 여부는 아직 미검증입니다.

## PC에서

1. Chrome 또는 Edge의 평소 사용하는 프로필로 공식 노벨피아에 구글 로그인합니다.
2. 확장 관리 페이지(`chrome://extensions` 또는 `edge://extensions`)에서
   개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**를 선택합니다.
3. 프로젝트의 `tools/novelpia-session-export` 폴더를 선택합니다.
   현재 Windows 경로는
   `C:\Users\skxod\programming\e-nobelpia\tools\novelpia-session-export`입니다.
4. 공식 노벨피아 탭을 활성화한 상태에서 확장 아이콘을 열고 **세션 파일 저장**을 누릅니다.
   v1.1.0부터 해당 탭의 서버 렌더링 로그인 표시를 먼저 확인하고,
   탭이 속한 쿠키 저장소를 명시적으로 선택합니다. 결과에는 로그인 상태와
   쿠키 개수만 표시하며 회원번호·쿠키 값은 표시하지 않습니다.
   OneDrive 등 동기화 폴더가 아닌 **로컬 폴더**에 저장하고,
   저장이 완료될 때까지 팝업을 열어 두세요.

이미 설치했다면 확장 관리 화면에서 **새로고침(↻)**으로 변경 코드를 반영하세요.
페이지 상태 확인을 위한 `activeTab`/`scripting` 권한이 추가되었습니다.
추가 권한 안내가 나오면 내용을 확인해야 합니다. 기존 APK와 파일 형식은 호환됩니다.

확장은 버튼을 누를 때만 해당 노벨피아 탭의 로그인 표시와 쿠키를 읽습니다. Google 도메인 접근 권한,
비밀번호 조회, 서버 전송, 분석, 상시 실행 기능은 없습니다.
내보내기 구현과 모의 테스트는 해당 폴더에 있습니다.

## 에뮬레이터 / 크레마에서

1. 파일을 USB/ADB로 기기의 Download 폴더에 복사합니다.
   에뮬레이터로 복사할 때 개발자에게 **파일 경로만** 알려줄 수 있습니다.
   JSON 파일이나 내용을 채팅에 첨부하지 마세요.
2. 앱의 **내서재 → PC 로그인 가져오기 · 구글 계정 → 파일 선택**에서
   파일을 선택합니다. 파일 선택기에서 보이지 않으면 Download 위치를 확인하세요.
3. 앱이 크기, 도메인, 만료, 내보낸 시각을 검증한 뒤 서버 로그인 상태를 확인합니다.
   24시간 이내에 내보낸 파일과 올바른 기기 날짜·시간이 필요합니다.
4. “로그인 확인됨” 후 **연동 검사**를 실행합니다.
   확인되지 않은 세션은 앱 메모리에서 지웁니다.
5. PC와 기기의 JSON 사본을 삭제하고, 필요 없어진 확장도 제거합니다.

**이 파일은 로그인 권한을 가진 민감한 정보입니다.** 깃, 채팅, 클라우드,
이메일, HAR/로그에 포함하지 마세요. 휴지통·백업에도 사본이 남을 수 있습니다.
실수로 노출했다면 공식 서비스에서 세션을 해제해야 합니다.

## 현재 가능한 검사와 한계

- 서버가 로그인 상태로 인정하는지 확인.
- 홈페이지의 “최애 작품” 최대 5개 슬롯 조회(전체 선호작과 다름).
- **최근 본 작품 / 전체 선호작은 아직 미구현**입니다. 로그인한 페이지의
  데이터 구조를 안전하게 확인한 뒤 추가해야 합니다. 0개라고 추측하지 않습니다.
- 구글 로그인 자체는 PC의 정상 브라우저가 담당합니다. 이 앱은 OAuth
  클라이언트나 구글 WebView 로그인 기능을 제공하지 않습니다.
- 앱 프로세스가 종료되면 다시 가져와야 합니다. “세션 지우기”는 이 앱의
  메모리만 비우며, PC 브라우저/서버의 다른 세션을 로그아웃하지 않습니다.
- 실제 로그인 후 APK 재설치·instrumentation은 앱을 재시작할 수 있으므로
  계정 검사는 **앱 안에서** 수행합니다.
- 계정 화면 스크린샷, UI hierarchy, 쿠키 원문을 진단 파일이나 로그에 남기지 않습니다.
  사용자가 직접 조작을 요청한 경우 `tools/account_ui_check.py`는 UI 구조를
  메모리에서 일시 처리해 알려진 검사 버튼을 누르고, 로그인 여부·목록 개수·
  고정 오류 코드만 출력합니다. 입력 화면에서는 조작을 중단합니다.
