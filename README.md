# 노벨피아 e-ink

크레마 카르타 G(Android 4.4 / API 19, 1GB RAM)를 목표로 만든 **비공식 네이티브 노벨피아 클라이언트**입니다. 공식 APK를 수정하거나 재배포하는 프로젝트가 아닙니다. 노벨피아와 제휴하지 않았습니다.

> **현재는 개발 프리뷰입니다.** APK가 설치된다는 것과 계정의 모든 회차를 읽을 수 있다는 것은 다릅니다. 이전 서재 빌드에서 이메일 로그인·최근 기록·전체 선호작·빈 최애 목록을 실제 계정으로 확인했습니다. 이번 UI 개편 검증은 합성 목록과 공개 콘텐츠를 사용했으며, 새 UI의 계정 재로그인·유료/PLUS 회차·크레마 실기기는 별도 검증 대상입니다. 상세 결과는 [`docs/VALIDATION.md`](docs/VALIDATION.md)에 기록합니다.

## 설계

- `minSdk 19`, Java, Android 기본 위젯. AndroidX/Compose/WebView/광고 SDK 없음.
- 검은 글자·흰 배경, 자체 디자인한 평면 버튼과 얇은 구분선. 화면 전환 애니메이션 없음.
- 나눔고딕을 번들로 포함해 시스템 한글 대체 글꼴이 없는 API 19 환경도 대응.
- 한 페이지씩 그리는 네이티브 리더, 16–36sp 글자 크기, 줄 간격 조절.
- 서재·탐색·회차·책갈피를 스크롤 대신 화면 단위로 이동. 서버 목록은 필요할 때 한 쪽씩 조회.
- 본문은 양옆 탭으로 넘기고 중앙 탭/햄버거로 읽기 도구를 표시. 기본 화면은 목록 버튼·작품명·회차 제목·진행 표시만 노출하며, 마지막 페이지에서는 다음 회차 버튼을 제공. 도구를 열어도 본문 레이아웃은 유지.
- 물리 버튼에 이전/다음/메뉴/새로고침을 직접 지정·해제. 기본 `PAGE_UP`/`PAGE_DOWN`, 볼륨 키는 명시적으로 지정한 경우만 사용.
- 소프트웨어 화면 명도(-40…40)·대비(80…160%)·채도(0…100%), 미리보기와 적용/취소 제공. 기본 흑백.
- 읽던 위치 및 최대 40개 주소 책갈피. 본문 다운로드/디스크 캐시 없음.
- 사용자 선택 UTF-8 TXT(1MiB / 30만 자 이하), 독립 동작하는 자체 작성 샘플.
- 웹 HTML에서 작품·회차 목록을 추출. 전체 웹 페이지와 광고 이미지를 렌더링하지 않음.
- 최근 본 작품·전체 선호작을 한 쪽씩 조회. 이전/다음 목록, 새로고침, 명시적 이어보기 선택.
- 선호작·알림·소장·최근 기록 탭. `마지막 읽은 EP.N`과 `등록 M편`은 별개 값으로 표시하며, 사이트에 없는 값은 추정하지 않음. 작가명과 직접 `이어보기`/`다음화` 버튼 제공.
- 다음화는 사이트의 실제 버튼 및 `get_next_episode` 응답으로 확인. **읽은 번호와 등록 편수가 같아도 다음 회차가 있을 수 있음**. 읽음 완료 여부나 최신 회차 번호를 편수로 계산하지 않음.
- 리더의 `목록` 버튼은 연속으로 읽은 회차를 건너뛰고 진입했던 서재 조건·화면 또는 회차 목록의 서버 쪽·화면으로 복귀. 직접 회차 주소를 열었다면 해당 작품의 회차 목록으로 이동.
- 서버 정렬 4종(공개일자순·조회순·등록순·추천순), 그룹 선택, 서재 검색·해제. 조건은 다음 서버 목록에도 유지되며 화면에 받은 일부 작품만 재정렬하지 않음. 최근 기록은 사이트와 동일하게 최근 본 순으로 고정.
- 선택적 이메일·비밀번호 암호화 저장 및 앱 시작 시 자동 로그인. 저장/자동 로그인은 기본 끔, 로그인 성공 후 선택한 경우만 저장.
- 홈페이지의 최애 작품 최대 5개는 전체 선호작과 별도 메뉴로 구분.
- 인증서/호스트명 검증을 유지하는 **앱 내부 Conscrypt TLS**. 시스템 인증서 수정·루팅·프록시 설치 없음.

## 빌드 및 설치

### 제공 빌드 스크립트 — Linux / WSL

필요 도구: Python 3, JDK 17+, Android SDK의 platform 및 build-tools(35/36 권장). WSL에서 Windows Android SDK의 `android.jar`, `d8.jar`, `apksigner.jar`도 재사용할 수 있습니다.

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/Android/Sdk
python3 tools/build.py
# API 19 platform을 갖고 있으면 더 엄격하게 컴파일:
python3 tools/build.py --api19-jar /path/to/android-19/android.jar
```

스크립트는 Google/Maven Central에서 버전이 고정된 의존성을 내려받아 SHA-256을 검사합니다. 시스템 SDK에 쓰지 않으며, 도구 캐시는 `.tools/`, 중간 산출물은 `build/manual/`에 둡니다. 빌드 후 Java 단위 테스트와 APK 서명 검증도 실행합니다.

출력:

```text
dist/novelia-0.1.0-preview.apk
dist/novelia-0.1.0-preview.apk.sha256
```

개발 키는 `.tools/debug.keystore`에 한 번 생성합니다. 키를 바꾸면 기존 앱에 덮어 설치할 수 없습니다. 이 키는 배포용 비밀키가 아니며 저장소에 커밋하지 않습니다. API 19를 위해 **v1(JAR) 서명**을 포함합니다. APK는 Conscrypt의 ARMv7/ARM64/x86/x86_64 네이티브 라이브러리를 포함합니다.

```bash
adb install -r dist/novelia-0.1.0-preview.apk
adb shell am start -n me.crema.novelia/.MainActivity
```

ADB를 사용하지 않으면 APK를 기기로 옮긴 뒤 파일 관리자에서 설치합니다. 기기의 알 수 없는 출처 허용 설정이 필요할 수 있습니다. **부트로더·시스템 파티션을 변경할 필요는 없습니다.**

### Android Studio / Gradle

`settings.gradle`을 프로젝트로 엽니다. AGP 8.7.3, Gradle 8.9, JDK 17, Android SDK 35를 사용합니다. Gradle wrapper 배포 파일은 포함하지 않았으므로, 설치된 Gradle 또는 Android Studio를 사용하세요.

```bash
gradle :app:assembleDebug :app:testDebugUnitTest
```

이 경로와 수동 빌드의 결과를 혼동하지 마세요. 실제 실행한 빌드 경로는 검증 문서에 기록합니다. `targetSdk 28`은 구형 기기 사이드로딩용 결정이며 Play Store 출시 설정이 아닙니다.

## 사용 순서

1. **메뉴 → 파일과 책갈피 → 리더 미리보기**에서 글자 크기·페이지 넘김·하드웨어 키를 확인할 수 있습니다.
2. **작품 찾아보기** 또는 **검색**에서 작품명/정확한 `https://novelpia.com/novel/숫자` 주소를 엽니다.
3. 로그인되어 있지 않으면 앱을 시작할 때 로그인 창이 열립니다. 이후에는 **메뉴 → 계정과 도움말 → 로그인 관리 → 이메일 로그인**으로 로그인합니다. 원하는 경우 **비밀번호 저장**, **자동 로그인**을 켭니다. 자동 로그인을 켜면 비밀번호 저장도 켜집니다. 이후 **저장된 로그인 설정**에서 자동 로그인 해제·저장 정보 삭제가 가능합니다. 구글 계정용 **PC 로그인 가져오기**는 제공하지만 실제 세션 전송 성공은 미확인이고 기기 내 구글 로그인은 미지원입니다.
4. 내서재에서 **선호작 / 알림 / 소장 / 최근 기록**을 선택합니다. 정렬·그룹·서재 검색을 적용하면 해당 조건의 첫 목록으로 이동하고, 이후에도 조건을 유지합니다. 행 오른쪽의 **이어보기 / 다음화**로 바로 읽거나 작품을 눌러 **EP.N 이어보기 / 다음 회차 읽기 / 회차 목록** 중 제공되는 동작을 선택합니다. `마지막 읽은 EP.N`은 읽었던 회차 번호입니다. 화면에 보이는 작품의 실제 최신 회차를 확인하면 `최신 EP.N`을 표시하며, 확인되지 않았을 때는 `등록 M편`으로 등록 편수만 표시합니다. 편수와 회차 번호를 비교해 다 읽었다고 판정하지 않습니다. 최애 작품 최대 5개는 별도 메뉴입니다.
5. 회차를 선택합니다. **메뉴 → 계정과 도움말 → 성인 모드**에서 현재 설정을 확인하고 켜거나 끌 수 있습니다. 성인 모드가 꺼져 있어 열람이 막히면 안내 창에서 **성인 모드 켜기**를 눌러 다시 열 수 있습니다. 로그인이나 본인인증이 필요한 경우에는 해당 동작을 안내합니다.
6. 본문 **왼쪽/오른쪽**을 탭해 페이지를 넘깁니다. **가운데 또는 우측 상단 햄버거**를 누르면 글자 크기·회차 이동·책갈피 등의 읽기 도구가 열립니다. 뒤로가기는 열린 도구부터 닫습니다.
7. **메뉴 → 화면 조정**에서 색을 미리 확인한 뒤 적용합니다. 채도는 이미 흑백인 본문에서는 차이가 없으며, 컬러 미리보기에서 효과를 확인할 수 있습니다. 기기 프런트라이트를 바꾸는 기능은 아닙니다.
8. **메뉴 → 물리 버튼**에서 동작 옆의 **바꾸기/누르기**를 누른 뒤 기기의 버튼을 한 번 누르고 **적용**합니다. 뒤로가기나 15초 시간 초과로 학습을 취소할 수 있습니다. 중복 지정은 차단하고, 홈·전원·뒤로 등 시스템 키는 보호합니다. 잘못 지정했으면 **해제** 또는 **기본값 → 적용**을 사용합니다.

실패 시 비밀번호·쿠키를 보내지 말고 **기기 OS 버전, 화면의 오류 문구, 공개 작품/회차 주소**부터 알려주세요. 필요하면 공식 APK나 민감정보를 제거한 로그인 후 요청 구조를 바탕으로 연동을 개선할 수 있습니다. 계정 테스트는 사용자가 직접 로그인하는 방식으로 진행해야 합니다.

## 보안·개인정보

- 저장을 켠 경우에만 이메일·비밀번호를 **AES-256-CBC + HMAC-SHA256**으로 암호화·변조 검증해 앱 전용 저장소에 저장합니다. 두 대칭 키는 모두 AndroidKeyStore의 RSA 키로 감싸 보관하며 평문 저장으로 우회하지 않습니다. 기기별 하드웨어 키 보관을 보장하지 않고, 루팅·변조된 OS에 대한 보안 보장도 아닙니다.
- 쿠키는 메모리에만 유지합니다. 자동 로그인은 앱 시작 때 저장 정보를 복호화해 공식 이메일 로그인 요청을 한 번 수행합니다. 인증 실패 시 자동 로그인을 해제하며, 네트워크 오류에 반복 재시도하지 않습니다. CAPTCHA/SNS 로그인에는 사용할 수 없습니다.
- **로그아웃**은 메모리 쿠키와 저장된 이메일·비밀번호를 삭제하고 자동 로그인을 끕니다. **저장 정보 삭제**만 선택하면 현재 메모리 세션은 유지합니다. 서버의 모든 로그인 세션을 해제하는 기능은 아닙니다.
- **사용자가 내보낸 세션 JSON은 별도의 민감한 파일**이므로 가져온 뒤 PC·기기의 사본을 직접 삭제해야 합니다. PC 세션을 성공적으로 가져오면 기존 이메일 자동 로그인은 꺼 다른 계정으로 다시 로그인되는 것을 방지합니다.
- 책갈피·읽은 회차 주소·위치·설정은 앱 전용 SharedPreferences에 남습니다. 가져온 TXT 본문/문서 URI는 저장하지 않습니다.
- 자동 백업을 끄고 화면 캡처/최근 앱 미리보기를 제한합니다. 루팅된 OS에 대한 보안 보장은 아닙니다.
- 통신은 허용된 HTTPS 호스트로 제한합니다. 인증서 오류 무시, 평문 HTTP 폴백, 비밀번호/응답 본문 로그는 사용하지 않습니다.
- 결제·이용권 자동 소모·대량 수집·구독/DRM 우회는 구현하지 않습니다.

## 한계

- 사이트 HTML/API는 공식 공개 SDK가 아닙니다. 변경에 따라 연동이 깨질 수 있습니다.
- TLS 보완은 **이 앱의 요청에만** 적용됩니다. 시스템 브라우저나 다른 앱을 고치지 않습니다.
- Conscrypt 2.5.2와 jsoup 1.15.4는 구형 OS 호환성을 위한 고정 의존성입니다. 최신 보안 유지보수 수준의 OS/브라우저를 대체하지 않습니다. KitKat 기기에서 금융·결제 등 민감한 작업은 하지 않는 것을 권합니다.
- 흑백 재그리기는 일반 Android 화면 갱신입니다. 크레마 전용 EPD 파형/전체 refresh API는 검증되지 않았습니다.
- 화면 조절은 앱 본문 및 미리보기의 픽셀 변환입니다. 시스템·설정 대화상자는 중립 색상을 유지하며, 기기 조명·EPD 파형·잔상 제거를 제어하지 않습니다.
- 주요 화면은 스크롤하지 않지만 긴 도움말·오류·시스템 파일 선택창에는 스크롤이 있을 수 있습니다. 가로 화면·큰 시스템 글꼴·실기기의 잔상과 성능은 추가 검증이 필요합니다.
- 서재 정렬·기존 그룹 필터·검색은 지원하지만 선호작 추가/삭제, 그룹 생성/이름 변경/작품 이동, 최근 기록 삭제는 수행하지 않습니다. 최애 작품은 홈페이지의 최대 5개 슬롯만 대상으로 합니다.
- 이미지 회차/만화, 기기 내 SNS 로그인, 결제, DRM 콘텐츠, 대량 오프라인 다운로드는 지원 범위가 아닙니다.
- 절전이 기본입니다. 화면 계속 켜기와 주기적 흑백 재그리기는 선택 기능입니다.
- 1GB 기기에서의 실제 배터리·메모리·잔상 효과는 실기기로 측정해야 합니다.
