# 노벨피아 세션 내보내기

Chrome/Chromium MV3 확장 프로그램입니다. 공식 노벨피아 사이트에 일반 브라우저에서 로그인한 다음 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 이 폴더를 선택하세요. 확장 아이콘을 열고 **세션 파일 저장**을 누르면 저장 위치 선택 창이 나타납니다. 생성된 `novelia-session.json`을 Android 앱에서 수동으로 가져온 뒤 파일을 삭제하세요. 다른 사람에게 파일을 전달하지 마세요.

`https://novelpia.com` 또는 `https://book.novelpia.com` 탭을 활성화하고 버튼을 누르세요. 클릭 전에는 페이지나 쿠키를 조회하지 않습니다. 클릭하면 해당 탭의 스크립트 **텍스트**에서 서버가 렌더링한 로그인 표시를 격리된 스크립트로 확인합니다(페이지 JS는 실행하지 않고 회원번호/HTML을 팝업으로 반환하지 않음). 로그인 확인이 불가능하거나 로그아웃 상태면 내보내지 않습니다. 확인 성공 시 탭에 연결된 브라우저 쿠키 저장소에서 노벨피아 도메인 쿠키만 읽습니다. Google 쿠키나 비밀번호를 조회하지 않으며 네트워크 전송, 분석, 확장 저장소 사용도 없습니다. 분할 쿠키는 포함하지 않습니다. 쿠키가 없거나 128개 또는 JSON UTF-8 128 KiB 초과 시 저장하지 않습니다. 팝업에는 쿠키 개수만 표시합니다. **브라우저 로그인 확인은 Android 앱의 로그인 검증을 대체하지 않습니다.** 파일은 data URL 대신 임시 Blob URL에서 다운로드하므로 다운로드 기록의 URL에 쿠키 JSON이 포함되지 않습니다. 팝업이 열린 동안 다운로드 완료/중단 이벤트를 받으면 Blob URL을 해제합니다. **다운로드가 끝나기 전에 팝업을 닫으면 팝업의 이벤트 리스너가 사라져 URL 해제를 보장할 수 없습니다.** 완료 또는 취소/중단될 때까지 팝업을 열어 두세요. 저장된 파일과 브라우저의 다운로드 기록도 별도로 관리하세요.

형식: `{ "format": "novelia-session-v1", "exportedAt": 1234567890, "cookies": [{ "name": "…", "value": "…", "domain": ".novelpia.com", "path": "/", "secure": true, "expirationDate": 1234567890 }] }`. 세션 쿠키에는 `expirationDate`가 없습니다. Android 앱의 **내서재 → PC 로그인 가져오기 · 구글 계정**에서 선택합니다. 앱은 24시간 이내에 내보낸 파일만 허용하고 서버 로그인 상태를 별도로 검증합니다. 자세한 절차는 `docs/GOOGLE_LOGIN.md`를 참고하세요.

모의 테스트: `node tools/novelpia-session-export/test.js` (브라우저 쿠키는 읽지 않음).
